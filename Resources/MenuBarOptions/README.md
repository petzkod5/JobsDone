Three clean white Peon-head options, derived as native vector glyphs from built-in image-generation concept exploration. Original generated drafts were too detailed at menu-bar size, so these production candidates use large transparent cutouts and solid white shapes.

A: Classic front-facing Peon.
B: Side profile.
C: Angular front-facing Peon.

Each option includes editable SVG, a transparent 256px PNG, and a 36px Retina PNG for an 18pt macOS menu icon. `options.json` contains the path geometry. Export with `swift scripts/export-menu-options.swift`. The user selected B/Profile; it is installed as the menu bar icon only. Help and notification toasts use the real Warcraft III Peon portrait.

Concept prompt set (built-in image_gen): minimal white Warcraft III Orc Peon head glyph, transparent background, wide ears, heavy brow, broad nose and tusks, legible at 18 pixels; variants were front-facing classic, right-facing profile, and angular mask. The original Peon portrait was used as a character reference in the initial concepts.
