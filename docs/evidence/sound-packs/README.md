# Settings evidence

`settings.png` is an NSView render of the production Settings controller from
`./scripts/test-native.sh` on macOS 26.6.2. The harness uses a separate app
identity and isolated preferences. It changes several controls before capture.
The Sound pack control shows the shipped Peon default.

The window compositor capture failed in this session. This image shows the
rendered document view, without window chrome. It does not prove audible
playback or notification delivery through macOS.
