# Security

Report vulnerabilities through [GitHub’s private reporting form](https://github.com/petzkod5/JobsDone/security/advisories/new).
Keep exploit details and private account data out of public issues.

Include the affected version, how you installed it, steps to reproduce, and
the impact. A small reproduction with fake data is best. Never include a real
GitHub token. If you exposed a credential, revoke it through GitHub immediately.

Security fixes target the latest release. Older versions do not have a separate
maintenance branch.
